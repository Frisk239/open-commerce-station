# HANDOFF：chanpin 可交互原型

视觉加一档（v2，**不要做图**）：`chanpin/STYLE-PASS.md`。上一版把人带去生图，已作废。


一个仓库、两种独立站口味（国内站 / 出海站）的可点原型。全部数据在内存里，用 sessionStorage 按浏览器标签页暂存：同一个标签里刷新、直接输 URL 都不丢；换标签或关窗即回到演示数据。

## Design Read（开工时写下，验收时对照）

1. **店面**：摄影主导的冷静品牌独立站（对标 Aesop / Allbirds 一类 DTC），冷灰白底 + 深松绿单一强调色，Manrope 字体（中文回退系统苹方/雅黑），大图大留白，购买路径极短：首页 → 商品 → 车 → 结账。
2. **后台**：安静的经营工具（Shopify / Linear 气质），同一色板同一字体、密度更高：左导航 + 可读表格 + 今日待办，没有英雄区、没有营销味，也不是 Excel。
3. **默认空白店**：仍是一家品牌的官网、只是还没上架：大留白 + 一句人话（「商品即将上架」），店名、页脚、四篇说明都在，不是「暂无数据」表格空态。


- 老板（后台）：`owner@demo.shop` / `demo`
- 顾客：`jane@demo.shop` / `demo`（预置了一笔待发货、一笔已发货订单）

## 5 分钟验收路径（照这个点）

1. **选出海站** → 进店面 `North & Pine`。随便点一件商品（比如 Linen Pillow Cover），选颜色尺寸，**加入购物车** → 右上角购物车 → **去结账**。
2. 被要求登录：用 `jane@demo.shop` / `demo`，回跳结账。填个地址、**选一种配送**、优惠码输 `WELCOME10`（减 10%）、点 **PayPal 付款**（假支付，1 秒成功）。
3. 看到**下单成功 + 邮件预览**（信头就是店名）。
4. 新标签开 `/global/portal`，老板账号登录 → 首页「待发货」多了一单 → 打开订单 → **填运单号 → 标记发货**。
5. 回店面标签，右下角**聊天窗**问「我的订单到哪了」：AI 能对上这一单和单号；再发「我要退款」：**转人工**。后台收件箱出现这条对话（带订单上下文）。
6. 同一订单页（顾客侧）能看到单号；点**申请退货** → 后台订单里**同意**：因为已发货，状态变「等顾客寄回」，点**确认收到退货**才变已退款。
7. 国内站 `/cn` 再走一遍：支付宝假成功、**微信按钮灰色「稍后开放」**、页脚有可点击的 ICP/公安备案链接。
8. 回到 `/` 选站页，把任一站点切到**空白店**：还是一家品牌站的样子（My Shop、人话空态、说明页空文案「店主尚未填写」），随时切回演示店。

## 路由一览

| `/` | 选站页：国内 / 出海两张卡，可切「演示店 / 空白店」 |
| `/{cn,global}` | 店面首页（大图 + 8 件商品 + 品牌一段） |

| `/{cn,global}/portal` | 后台首页：待发货 / 待处理退货 / 未读聊天、最新订单、空说明提醒、来单邮件预览、空白店切换 |

| `/{cn,global}/portal/products`、`/products/new`、`/products/[id]` | 商品管理：选项名自己起，款式矩阵各自价格/划线价/库存，双语文案栏，示例图可换 |

| `/{cn,global}/portal/discounts` | 优惠码：比例减 / 固定减，启用停用 |

| `/{cn,global}/portal/settings/…` | 店铺资料（店名/标志/小图标/页脚/备案，仅国内有备案栏）、收款（微信灰）、运费、语言和货币（汇率手填）、发信设置（SMTP 表单 + 测试按钮，不真发）、在线客服开关 |

## 假支付的边界

支付宝 / PayPal / Stripe 全是本地假按钮，点击后 1.2 秒本地成功，**没有任何对支付宝或 Stripe/PayPal 的网络请求，没有真密钥**。微信按计划显示为灰色「稍后开放」。

## 原型数据的行为

- 数据在内存（zustand），按标签页存 sessionStorage：刷新、直接输 URL、返回前进都不丢；关标签即回种子数据。
- 选站页或后台首页的「演示店 ⇄ 空白店」切换会把当前一份数据快照换进换出：在空白店里做的修改切回演示店就看不到了，再切回去仍在。要干净重来，关掉标签重开即可。

## 技术备注（给接手的工程师）

- Next.js 15 App Router + TypeScript + Tailwind v4 + pnpm，全部交互页为客户端组件，状态在 `src/mock/store.ts`（zustand + sessionStorage persist）。
- 假数据种子在 `src/mock/seed.ts`（两家店各 8 件家居物、两笔预置订单、WELCOME10 优惠码、说明页文案）。空白店工厂 `makeBlank`。
- 软件文案：`src/lib/i18n.ts` 中英两包按 key 取字，缺了回退中文包；店的内容（商品名、说明页、首页文案）按语言各带一份，没译回退主语言。
- 假 AI：`src/lib/chat-engine.ts`，规则：退款词必转人工；退货/运费答说明页；订单对登录顾客当前单；其余兜底。AI 永远不能同意退款。
- 三封邮件（下单成功 / 已发货带单号 / 老板来单）用 `MailPreview` 组件按订单实时渲染，信头与页眉、结账同源（店铺资料）。
- 图片来自 picsum.photos 固定 seed，统一 4:5 裁切 + 轻微降饱和，保证两店照片气质一致；后台「换一批示例图」就是换 seed。
