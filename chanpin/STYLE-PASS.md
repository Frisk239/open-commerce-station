## 1. 为什么现在不够吸睛（和图片无关）

| 现在 | 问题 |
| --- | --- |
| Hero 字 `text-3xl / sm:text-5xl` 叠在图下居中偏下 | 免费主题默认，停不住目光 |
| 下面 2×4 一样大的格子 | 像目录，不像品牌首页 |
| 全站 Manrope | 标题和按钮一个脸 |
| `rounded-xl` + 聊天顶栏整条深绿 | 像组件库和客服软件 |
| 客服 `bottom-5 right-5 z-40` | 手机上压住购买条和付款 |

别人吸睛靠：**特大标题、不对称版面、界面让路**。照片重要，但本刀明确不做图。布局对了，现有图也会好看一档。

## 2. 客服钮（先做这个，半小时内必须落地）

不要拖。

## 3. 字和首页（吸睛的主体）

**字**

- `next/font` 加一套显示用无衬线（Syne 或 Outfit，只选一个）。Hero 和首页大标题用它。
- 顶栏、价格、表单、后台继续 Manrope。
- 桌面 Hero 大约 `text-5xl lg:text-7xl`，字距收紧，最多两行。
- 禁止 Inter、Fraunces、Instrument Serif、第三套字。

**首页（改 `src/app/[flavor]/(shop)/page.tsx`）**

1. Hero：不要「图上垂直水平居中的海报」。左文（纸色或深色块）右图，或图铺满、字**只锚左下**。一个按钮。不要 Scroll 提示。
2. 第一件可售商品：**桌面占两列**，大图 + 店名一句人话 + 价格 + 链到详情。不要写「FEATURED」。
3. 其余商品：三或四列，卡不要盒子边框。
4. 「关于」保留左右图文，不要第三组均分卡片。

手机全部单列。Hero 高度用约 `70svh`，不要 `h-screen`。

**详情**

- 选项继续是按钮，不要变下拉。
- 拆掉详情里那块绿边「运费说明盒」，改成细文字链。
- 吸底购买条保留。

**顶栏**

- 更薄。桌面搜索可先是图标。

**结账**

- 保持安静。运费为 0 时跟当前语言显示，不要写死 `Free`。
