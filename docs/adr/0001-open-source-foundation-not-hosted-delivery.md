# Open-source Foundation, source only

This repository is an open-source Foundation for a real Independent Station. We publish source; we do not operate a hosted product, sell multi-tenant SaaS, or deliver turnkey sites as a service. That keeps the two store apps as independently deployable product boundaries a Merchant (or their developer) runs themselves, instead of a platform we run for them.

**Status:** accepted

**Considered Options:** hosted SaaS; agency-style turnkey delivery; source-only Foundation

**Consequences:** Prototypes in `chanpin/` and later implementation must look like a store you own and run, not an admin of a platform that owns the merchant. Deployment, hosting, and go-live remain outside this project's job.
