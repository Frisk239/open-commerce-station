# One deploy, one station flavor

China Station and Global Station are separate products. The Merchant chooses which to deploy. Shared Catalog / order language may exist in source, but a running station is not a dual-region Portal. Selling in both markets means two deploys, two Portals, two Storefronts.

**Status:** accepted

**Considered Options:** one Portal managing both regions; a multi-store platform; one Independent Station per deploy

**Consequences:** `chanpin/` prototypes the two flavors as two stations that can share interaction patterns, not as one shop-switcher. Core sameness is in domain language, not in a combined merchant workspace.
