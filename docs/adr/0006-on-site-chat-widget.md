# Storefront Contact is an on-site chat widget

Shoppers start support from an in-site chat widget, which is the common Independent Station pattern (Shopify Inbox-class). The first Storefront door is not a WeChat QR or WhatsApp `wa.me` jump. Those channels may later feed the same Inbox; they are not the default Storefront Contact.

**Status:** accepted

**Considered Options:** messenger launcher only; widget plus launcher as co-equal doors; on-site widget as the Storefront door

**Consequences:** `chanpin/` Storefront shows a chat widget. China Station still uses the widget on the site, not a scan-to-WeChat homepage. Inbox in the Merchant Portal receives those widget threads.
