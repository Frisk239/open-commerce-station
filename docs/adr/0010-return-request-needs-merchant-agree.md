# Return requests wait for the Merchant; AI cannot pay out

Shoppers file a Return Request. The Merchant agrees or refuses. Unshipped orders refund after agree; delivered goods come back (or the Merchant agrees another deal) before money moves. This is a branded Independent Station, not a marketplace that force-refunds.

AI Support is a plug-in in the same chat: first answers, then staff take over. It must not approve refunds. Asking for a person always reaches a human when staff are available.

**Status:** accepted

**Considered Options:** instant refund on click; marketplace-style 仅退款; AI issues refunds; request plus Merchant agree, AI assists then hands off

**Consequences:** Portal has a queue of requests to agree or refuse. Chat and “my orders” can start a request. AI is a slot the Merchant can turn on, not a second app. First prototypes can show the request and the agree/refuse; AI plug-in can follow.
