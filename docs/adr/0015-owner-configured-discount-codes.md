# Owner sets sell prices and discount codes in the first version

Both ship in the first version. Sell Price (optional crossed-out original) is what everyone sees on the product. A Discount Code is a string the owner creates for a person or campaign, typed at checkout. 拼团 and 砍价 stay out. A code comes off the Sell Price, not the crossed-out original. One code per checkout.

**Status:** accepted

**Considered Options:** codes only; markdown only; both later; both in v1

**Consequences:** Product form has sell price and optional original. Portal has a simple codes screen. Checkout can take one code. Do not build a campaign studio.
