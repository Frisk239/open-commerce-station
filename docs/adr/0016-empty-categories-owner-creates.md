# Empty categories; the owner creates them

The Foundation does not ship clothing or electronics category trees. The owner creates groups. The Storefront always has an all-products list so an empty new station can still be browsed after the first product is added.

**Status:** accepted

**Considered Options:** preset industry categories; empty owner-created groups

**Consequences:** Portal has a simple place to add and nest groups. First `chanpin/` can show “all products” plus one owner-made group.
