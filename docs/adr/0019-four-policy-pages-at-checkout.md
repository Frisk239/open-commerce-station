# Four policy pages at checkout; empty does not block pay

Privacy, terms, returns, and shipping are four reserved Storefront pages. Checkout and the footer always link them. Empty body shows “店主尚未填写” and does not block payment. The Portal reminds the owner which pages are still empty.

**Status:** accepted

**Considered Options:** block checkout until filled; links only when content exists; four reserved pages always linked

**Consequences:** `chanpin/` checkout footer has four links. New store already has the four titles. Store identity footer uses the same pages.
