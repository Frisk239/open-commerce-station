# TypeScript for storefront, portal, and plugins

The Foundation is written in TypeScript. Storefront, Merchant Portal, shared core, and payment plugins use one language. This matches the already-validated PayPal, Stripe, and Alipay Node test libraries. We do not adopt Medusa or Vendure as the product.

**Status:** accepted

**Considered Options:** TypeScript; PHP; Java

**Consequences:** `chanpin/` and later apps target a TypeScript toolchain. PHP and Java clones stay study material only.
