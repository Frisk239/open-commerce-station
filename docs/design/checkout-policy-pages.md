# 结账旁的说明页

四篇固定说明：隐私、服务条款、退货说明、运费说明。都是店里的页面，老板自己写。结账页和页脚都挂这四个链接。空着也能付款，空页显示「店主尚未填写」。后台在「要开始卖了」时提醒还没填的篇。

## 四篇

| 页面 | 顾客来干什么 |
| --- | --- |
| 隐私 | 店收了哪些信息、怎么用 |
| 服务条款 | 买卖约定 |
| 退货说明 | 怎么申请、谁同意、货怎么寄回 |
| 运费说明 | 怎么计价、多久发、送到哪 |

不是法律中心，也不是再上传 PDF。出海、国内都是这四篇，正文老板按市场自己写。

## 出现在哪

- 结账页底部，四个链接都在，不藏进菜单。
- 店面页脚：有这篇才出链接；四篇系统都预留了，所以正常都会出现。空页仍然可点，点进去看到「店主尚未填写」。
- 购物车、商品页不强制再挂一遍。

## 空页和提醒

- 新店自动有这四个标题的空页，不必老板先「新建页面」才有链接。
- 没写正文：页面能打开，正文为「店主尚未填写」，付款不拦截。
- 后台店铺资料或首页给一条提醒：还有哪篇是空的。提醒可关掉，不挡上架。

## 不做

不代写法律文本。不因空页拒绝收款。不把备案号写进这四篇（备案在页脚，见店铺资料）。
