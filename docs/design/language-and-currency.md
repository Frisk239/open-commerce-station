# 语言和货币

老板自己开哪些语言、哪些货币。软件里的字不写死成一种语言。第一版我们只随包带 **中文、英文** 两套软件译文；店里的商品名和说明页由老板按他打开的语言来写。

## 三套东西

| | 谁写 | 第一版 |
| --- | --- | --- |
| 软件的字（按钮、后台、邮件固定句） | 项目自带中文、英文 | 用编号取字，缺了退回店的主语言 |
| 老板的内容（商品、四篇说明、分类名） | 老板 | 每种打开的语言各填一份；没填就显示主语言 |
| 货币 | 老板勾选 | 一种记账货币 + 可多种给顾客看和付 |

语言和货币分开切。国内站默认：中文、人民币。出海站默认：英文、美元。老板都能再加。

## 软件的字

- 源码里不出现写死的「结算」「保存」。写成编号，中文包、英文包各给一句。
- 只维护中、英两包。法、日等以后加语言包，不必改页面。
- 后台界面：老板选中文或英文（软件语言）。
- 店面按钮：跟顾客当前语言走；该语言没有软件包时用店的主语言。

## 老板的内容

- 店有一个 **主语言**（必有，删不掉）。新商品先写主语言。
- 老板打开的其他语言：同一商品、同一说明页多一栏译文。空着就给顾客看主语言，不要留空白标题。
- 四篇说明页也按语言各写。结账链接还是那四个位置。

## 货币

- **记账货币** 一种：后台看的销售额、库存成本用它。
- 老板可再打开别的货币。顾客切货币后，标价按老板填的汇率（相对记账货币）换算；第一版手填汇率，不接牌价接口。
- 结账：尽量按顾客当前货币收款（通道支持才行）。不支持则退回记账货币并写清楚。
- 优惠码减的是结账用的那笔钱。划线原价跟现价同一货币。
- 国内默认只开人民币；出海默认美元，老板可加欧元等。

第一版不做：按国家自动换价、自动拉汇率、二十种后台语言。

## 后台

**设置 → 语言和货币**

- 主语言、打开哪些语言  
- 记账货币、打开哪些货币、每条相对记账货币的汇率  
- 老板自己的后台显示语言（中 / 英）

商品编辑：主语言正文 + 已开语言的译文栏。

## 验收（给 `chanpin/`）

1. 出海店切到中文：按钮变中文；没译的商品名仍是英文主语言。  
2. 改汇率，店面价格跟着变。  
3. 国内店设置里默认中文+人民币，仍能再开英文。  
4. 后台可在中/英界面之间切换，店面语言不受影响。
