# 这家店是谁

店名、标志、页脚从同一处填写，店面、结账、邮件、浏览器标签共用。老板在后台改，不用改代码。第一版只有一套默认空白店，这里不换皮肤。

对照：Shopify 把店名放在设置里的「店铺资料」，标志单独上传，结账页再取同一套；国内站页脚要能挂备案号并点到工信部 / 公安查询页。InnoShop 也是系统设置里的店标，不是每个页面各传一张。

## 后台：一个页面

路径：**设置 → 店铺资料**

| 字段 | 谁填 | 空着时 |
| --- | --- | --- |
| 店名 | 必填 | 保存不了。未填过的新店可用「我的店」占位，提示尽快改 |
| 标志 | 选填，一张横图 | 页眉、结账、邮件只显示店名文字 |
| 小图标 | 选填，一张方图 | 没有则用标志裁方；再没有用默认空白店图标 |
| 顾客能看见的联系邮箱 | 选填 | 用发信邮箱；再没有则页脚不显示邮箱 |
| 页脚一行字 | 选填 | 自动 `© 今年 店名` |
| ICP 备案号 | 仅国内站，选填 | 页脚不显示该项，不造假号 |
| 公安备案号 | 仅国内站，选填 | 同上 |
| 公安备案小图标 | 仅国内站，选填 | 有公安号、无图标时只显示文字 |

出海站不出现备案三个字段。

规则：

- 店名出现在：浏览器标题、没标志时的页眉、邮件标题和落款、结账页顶栏。
- 标志出现在：页眉、结账页顶栏、那三封通知邮件的页眉。同一张图，不让老板传三遍。
- 小图标只用于浏览器标签。
- 图片：常见 jpg / png / webp。标志建议够宽、背景可透明；小图标建议正方形。第一版不做在线抠图。
- 备案号填了就必须能点：ICP 点到 `https://beian.miit.gov.cn/`；公安号点到公安查询（号填进去后拼官方查询地址）。不要做成「只显示不能点」。
- 系统不替老板办备案，只提供位置。没号就不挂，避免空链或假号。

不做：品牌色盘、第二套方形社交头像、页脚富文本编辑器、在页脚贴整段 HTML。

## 店面页脚长什么样

从上到下，能省则省：

1. 指向说明页的链接：隐私、服务条款、退货说明——有这篇页面才出现，没有不留空链。
2. 联系邮箱（有才显示）。
3. 那一行版权字。
4. 国内站：ICP、公安号（有图标则图标贴在公安号左边），同一行或折行都可以，但必须在第一屏往下拉就能看见，不能藏进菜单。

出海站没有第 4 行。

## 空店默认

部署刚完成、老板还没改：

- 店名：我的店
- 标志：无
- 页脚：`© 今年 我的店`
- 备案：空

后台进店铺资料时，店名输入框提醒改成真名。店面可以先用占位名开着，不挡上架。

## 和别的块怎么接

- 通知邮件的「从哪家店发来」用店名；信头用标志或店名。发信邮箱仍在「发信设置」，不和店名混在一个字段。
- 结账顶栏用同一店名 / 标志，不单独再做一套结账品牌。
- 说明页（隐私、条款、退货）是店铺说明书，链接出现在页脚和结账旁；正文不在本页编辑。

## 验收（给 `chanpin/`）

1. 老板改店名、上传标志，店面页眉、结账顶栏、邮件预览一起变。
2. 去掉标志，三处都改回店名文字。
3. 国内站填 ICP，页脚出现且能点到工信部；清空则消失。
4. 出海站设置里没有备案栏。
5. 没有隐私页时，页脚没有「隐私」死链。
