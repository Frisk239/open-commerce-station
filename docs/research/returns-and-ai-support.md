# 退款申请和客服怎么配合

给产品讨论用，不是技术选型。

## 外面独立站普遍怎么做

顾客点「申请」时，钱不会马上回去。店家先看，同意或拒绝。

两条常见路：

1. **还没发货**：申请取消 → 店家同意 → 原路退款，不用寄货。
2. **货已经到**：申请退货 → 店家同意 → 告诉怎么寄回来 → 店家确认收到 → 再退款。

店家也可以在聊天里谈妥后，自己在后台点退款。独立站没有淘宝那种平台强行「仅退款」。

参考：[Shopify 顾客自己申请退货](https://help.shopify.com/en/manual/fulfillment/managing-orders/returns/self-serve-returns)（店家在后台同意或拒绝）。

## 客服在这里干什么

申请可以在「我的订单」里填，也可以在站内聊天里说。谈不拢、情况特殊，必须转到人。

AI 客服外面普遍只做：答商品、答政策、查物流。复杂或涉及退钱，交给人工。顾客说「找人」也要能转。AI 不自己把钱退出去。

参考：[Shopify Inbox 转人工](https://help.shopify.com/en/manual/inbox/assigning-your-ai-staff-member)。
